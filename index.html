Omni Moon - streaming demo

A real-data Moon (NASA LRO LOLA heights, LROC colors), streamed over HTTP Range from this site and refined from the whole globe down to the ground. The HUD shows how much data has arrived, the number of requests and the cache hits.

Open the demo

Requires a browser with WebGPU (recent desktop Chrome or Edge). The first run downloads about 12 MB while you fly; a second visit reuses the browser cache (IndexedDB).

Data: NASA LRO LOLA and LROC (public domain), see NOTICE. File list and checksums: manifest.json.
