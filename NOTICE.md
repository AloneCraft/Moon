# Notice

## Data

The Moon data in `MoonPacks/` is derived from NASA data, which is in the public domain:

- Elevation: NASA Lunar Reconnaissance Orbiter (LRO) Lunar Orbiter Laser Altimeter (LOLA), as distributed by the NASA Scientific Visualization Studio (SVS 4720, "CGI Moon Kit"), 16 pixels per degree.
- Color: NASA LRO Camera (LROC) color mosaic, from the same SVS 4720 release (4096 x 2048).

The packs are re-encoded for streaming (elevation in 0.5 m steps, color as BC1 tiles) and are not the original products. NASA does not endorse this work.

`WebGPU/` is a Unity 6 (6000.6.6f1) WebGPU build of a demonstration scene. It is published only to show the demo running in the browser. No license is granted for reuse of the player build beyond viewing it.
